# Due Diligence

Beyond surface-level analysis, NotebookLM helps with deeper due diligence — finding specific disclosures, tracking changes, and identifying potential red flags.

---

## Due Diligence Checklist Queries

These questions target specific disclosure requirements:

### Related Party Transactions

```
What related party transactions are disclosed?
```

```
Are there any transactions with executives, board members, or their affiliates?
```

### Legal Proceedings

```
What legal proceedings or litigation are mentioned?
```

```
Are there any material pending lawsuits?
```

### Accounting Policies

```
What significant accounting policies are described?
```

```
Were there any changes in accounting methods this year?
```

```
What critical accounting estimates does management discuss?
```

### Customer and Supplier Concentration

```
Who are the largest customers? What percentage of revenue do they represent?
```

```
Is there any supplier concentration risk discussed?
```

### Debt and Financing

```
What are the terms of the company's debt agreements?
```

```
Are there any debt covenants mentioned? Has the company violated any?
```

```
What maturities are coming up in the next few years?
```

## Red Flag Hunting

Some questions specifically look for problems:

```
Are there any going concern warnings or statements?
```

```
What does the auditor's report say? Any qualifications?
```

```
Are there any restatements of prior financials mentioned?
```

```
What material weaknesses in internal controls are disclosed?
```

```
Are there any SEC inquiries or investigations mentioned?
```

---

## Year-Over-Year Due Diligence

Upload multiple years and look for changes:

```
What new risk factors appeared this year?
```

```
Were any risk factors removed? Which ones?
```

```
How has the language around [specific issue] changed?
```

```
What new legal proceedings appeared?
```

Changes in disclosure language often signal emerging issues.

## Proxy Statement (DEF 14A) Analysis

Add the proxy statement for governance-focused due diligence:

```
What is the executive compensation structure?
```

```
How are board members compensated?
```

```
What related party transactions are disclosed in the proxy?
```

```
What shareholder proposals were included?
```

## 8-K Filings for Recent Events

8-Ks cover material events between quarterly filings:

```
What material events were disclosed in recent 8-Ks?
```

```
Were there any management changes announced?
```

```
What acquisitions or divestitures are described?
```

## Building a Due Diligence Notebook

For serious due diligence on a potential investment:

**Sources to include:**
- Last 2-3 annual 10-Ks
- Recent quarterly 10-Qs
- Latest proxy statement (DEF 14A)
- Recent 8-Ks (material events)
- Earnings call transcripts

This gives NotebookLM comprehensive coverage for thorough questioning.

---

## Sample Due Diligence Workflow

**Phase 1: Business Understanding**
```
What does this company do and how does it make money?
```

**Phase 2: Risk Assessment**
```
What are the most significant risk factors? List the top 10.
```

**Phase 3: Financial Health**
```
What does the company say about its liquidity and capital resources?
```

**Phase 4: Governance Check**
```
What related party transactions exist? Any potential conflicts?
```

**Phase 5: Legal/Regulatory**
```
What legal proceedings or regulatory matters are disclosed?
```

**Phase 6: Change Detection**
```
Comparing this year to last year, what significant changes appear in disclosures?
```

**Phase 7: Red Flags**
```
Are there any going concern warnings, restatements, or internal control weaknesses?
```

## What Due Diligence NotebookLM Can't Do

- **Verify claims** — It reports what filings say, not whether they're accurate
- **Ratio analysis** — Can't calculate financial ratios or trend analysis
- **Market comparison** — Can't compare to industry benchmarks
- **News integration** — Doesn't know about subsequent events not in your sources
- **Fraud detection** — Can surface disclosures but can't identify fraud

NotebookLM accelerates the document review phase. The judgment calls are still yours.
