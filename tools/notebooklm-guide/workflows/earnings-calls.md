# Earnings Calls

Earnings calls give you the freshest commentary from management — quarterly updates, analyst Q&A, and forward guidance. NotebookLM helps you extract insights without listening to 90-minute calls.

---

## Getting Transcripts

**Free sources:**
- Company IR websites (some provide transcripts)
- Seeking Alpha (free tier has recent transcripts)
- SEC EDGAR (8-K filings sometimes include transcripts)

**Paid sources:**
- FactSet, Bloomberg, Refinitiv
- AlphaSense, Koyfin
- Earnings Call Pro

Download as text/PDF or copy-paste into Google Docs.

---

## Setup

**Option A: Add to existing company notebook**
Upload the earnings transcript alongside the 10-K for comprehensive coverage.

**Option B: Dedicated earnings notebook**
Create a notebook with just earnings calls if you want to track commentary over time (e.g., last 4 quarters of calls).

## Key Questions for Earnings Calls

### Management Commentary

```
What did management say about the quarter's performance?
```

```
What forward guidance was provided?
```

```
Did management raise, lower, or maintain guidance compared to last quarter?
```

### Analyst Q&A

The Q&A section is often more revealing than prepared remarks.

```
What questions did analysts ask about [specific topic: margins, growth, competition]?
```

```
Summarize the analyst Q&A section. What themes emerged?
```

```
What questions did management seem to avoid or deflect?
```

### Specific Topics

```
What did management say about AI/machine learning investments?
```

```
How did they explain the margin changes?
```

```
What comments were made about the competitive environment?
```

## Multi-Quarter Analysis

Upload several consecutive quarters' transcripts:

```
How has management's tone about growth changed over these four quarters?
```

```
Track what management said about [specific initiative] across calls.
```

```
What new topics appeared in the most recent call that weren't discussed before?
```

## Comparing to 10-K

When you have both 10-K and earnings calls in one notebook:

```
Does recent earnings commentary contradict anything in the 10-K risk factors?
```

```
What's discussed in earnings calls that isn't covered in the annual report?
```

```
Has management's strategic messaging stayed consistent between the 10-K and recent calls?
```

## YouTube Integration

If the earnings call is on YouTube:

1. Find the video URL (many companies post to their IR YouTube channels)
2. Add the URL as a source
3. NotebookLM extracts the transcript automatically

> Note: This only works if the video has captions/transcripts available.

## What Earnings Calls Are Good For

- **Freshest commentary** — More recent than any filed documents
- **Management tone** — How confident do they sound?
- **Analyst concerns** — What's Wall Street focused on?
- **Details not in filings** — Specific product updates, deal commentary

## What They're Bad For

- **Precision** — Numbers stated verbally should be verified in filings
- **Legal weight** — 10-K is audited, earnings calls are not
- **Complete picture** — Calls highlight what management wants to emphasize

---

## Sample Workflow

1. **Upload transcript** after earnings are released

2. **Quick summary:** "Give me the highlights of this earnings call in 5 bullet points"

3. **Guidance:** "What specific guidance did management provide for next quarter and full year?"

4. **Surprises:** "What unexpected topics came up in the analyst Q&A?"

5. **Concerns:** "What seemed to concern analysts based on their questions?"

6. **Compare:** "How does this quarter's commentary compare to last quarter?" (if you have both)
