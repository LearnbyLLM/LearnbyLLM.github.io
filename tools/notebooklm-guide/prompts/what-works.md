# Prompts That Work

Copy-paste these. They're designed for investment research and tested to work well with NotebookLM.

---

## General Principles

**Be direct.** No need for "please" or "Act as a financial analyst." Just ask what you want.

**Be specific.** "Summarize the risks" is okay. "List the top 5 risk factors related to supply chain" is better.

**Request format when useful.** "As bullet points," "in a table," "in 3 sentences."

**Ask for citations.** "Include source citations" helps verify answers.

---

## Getting Oriented

When you first add a document:

```
Give me a 5-sentence overview of this company.
```

```
What are the main themes in this document?
```

```
What's the most important information in this filing for an investor?
```

## Business Understanding

```
How does this company make money? Break down revenue streams.
```

```
What are the main products or services?
```

```
Who are the target customers?
```

```
What does the company say about its competitive advantages?
```

```
Describe the company's business model in simple terms.
```

---

## Risk Assessment

```
List all risk factors mentioned, grouped by category (operational, financial, regulatory, market).
```

```
What are the top 5 risks I should care about as an investor?
```

```
What does management say about competition as a risk?
```

```
What supply chain risks are disclosed?
```

```
Are there any risks related to customer concentration?
```

---

## Financial Questions

> Remember: Always verify numbers. These prompts help you find information, but check the actual figures.

```
What were the key financial metrics (revenue, net income, operating margin)?
```

```
How does management explain the financial results this year?
```

```
What does management say about capital allocation (dividends, buybacks, reinvestment)?
```

```
What debt does the company have and what are the terms?
```

---

## Management & Strategy

```
What strategic priorities does management outline?
```

```
What does management say about future growth?
```

```
How does the company discuss R&D investments and focus areas?
```

```
What forward-looking statements are made? Note the disclaimers.
```

---

## Comparative Questions

When you have multiple sources (e.g., multiple companies or multiple years):

```
Compare how Company A and Company B describe their competitive positioning.
```

```
What risk factors appear in all filings? Which are unique to each company?
```

```
How has the company's strategic narrative changed between 2023 and 2024?
```

```
What new topics appeared in the latest filing that weren't in the previous one?
```

---

## Earnings Call Specific

```
Summarize the key points from management's prepared remarks.
```

```
What guidance was provided for next quarter and full year?
```

```
Summarize the analyst Q&A. What were analysts focused on?
```

```
Did management raise, lower, or maintain guidance? How do they explain it?
```

```
What questions seemed to make management uncomfortable?
```

---

## Due Diligence

```
What related party transactions are disclosed?
```

```
What legal proceedings or litigation are mentioned?
```

```
Are there any going concern warnings?
```

```
What material weaknesses in internal controls are disclosed?
```

```
What does the auditor's report say?
```

## Format Requests

Add these to any prompt to shape the output:

```
...in bullet points
```

```
...in a table format
```

```
...in 3 sentences or less
```

```
...with source citations for each point
```

```
...quote the exact language from the filing
```
